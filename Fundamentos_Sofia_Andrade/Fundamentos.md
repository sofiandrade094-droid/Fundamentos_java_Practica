# Intro Java
Una introducción a Java implica entender que, para que la computadora pueda leer tus instrucciones de salida, necesitas una estructura mínima obligatoria.


                         EJEMPLO
 public class Name {
  public static void main(String[] args) {
    String name = "John";
    System.out.println("Hello " + name);
  }
}

# System.out.println()
 es la instrucción más utilizada en Java para mostrar datos en la pantalla. Su característica principal es que imprime el contenido y automáticamente hace un salto de línea




                       EJEMPLO

public static void main(String[] args) {
  System.out.println("Hello World");
}



# Sentencias Java
Las sentencias en Java son las líneas de código que le dicen a la computadora qué acción debe realizar.

                        EJEMPLO
System.out.println("Hello World!");
System.out.println("Have a good day!");
System.out.println("Learning Java is fun!");


# Salida/Impresión de Java
La salida o impresión en Java es la forma en la que el programa muestra mensajes, datos o resultados en la pantalla para que el usuario pueda verlos.

                         EJEMPLO

  public static void main(String[] args) {
    System.out.println("Hello World!");
    System.out.println("I am learning Java.");
    System.out.println("It is awesome!");
  }

# Comentarios de Java
Los comentarios pueden utilizarse para explicar el código Java y hacerlo más legible. También pueden usarse para impedir la ejecución al probar código alternativo.

                          EJEMPLO
 
  public static void main(String[] args) {
    // This is a comment
    System.out.println("Hello World");
  }
